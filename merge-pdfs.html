❓ Merge PDFs FAQ

🔒 Is it safe to merge confidential bank statements or contracts here?

Yes, absolutely! The `pdf-lib` engine compiles the binary PDF streams locally within your browser's JavaScript sandbox. The files are never sent over any network or stored on any server.

📑 Is there a file size or page count limit?

There are no server limits or artificial paywalls. You can merge as many pages as your device's available memory can accommodate.
