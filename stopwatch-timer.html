❓ Stopwatch & Timer FAQ

⏱️ How accurate is this browser stopwatch?

It uses `performance.now()` high-resolution monotonic timestamps, ensuring microsecond hardware precision unaffected by system clock adjustments.

🔔 How does the alarm sound without external audio files?

We synthesize pleasant chime alert chords natively using the browser's Web Audio API (`AudioContext`). It works completely offline with zero loading time.
